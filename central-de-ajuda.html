Central de Ajuda

Aprenda a usar a Rota dos Celulares 66

Um guia simples, em 15 passos, para você encontrar fornecedores, usar a busca e os filtros, e saber como funciona cada botão da plataforma.

1O que é a Rota dos Celulares 66

É um catálogo pós-compra: aqui você encontra fornecedores de celulares, smartphones, eletrônicos e acessórios organizados por categoria, com o contato ou a comunidade de cada um.

2Como usar a busca

Na página inicial, use o campo "Buscar fornecedor, produto ou categoria". Os resultados do catálogo atualizam automaticamente enquanto você digita — sem precisar apertar nenhum botão.

3Como usar o filtro de Categoria

Selecione uma categoria (ex.: Xiaomi, iPhones e produtos Apple) no menu "Categoria" para ver só os fornecedores daquele tipo. Também dá para clicar diretamente nos cartões da seção "Categorias".

4Como usar o filtro de Marca

O menu "Marca" mostra as marcas cadastradas (Apple, Xiaomi, Realme, Motorola etc.). Escolha uma para ver só os fornecedores que trabalham com ela.

5Como usar o filtro de Tipo de produto

Use o menu "Tipo de produto" para filtrar por itens específicos, como iPhone Seminovo, Acessórios ou Peças e componentes.

6Como usar o filtro de Fornecedor

Se você já sabe o nome do fornecedor que procura, selecione-o diretamente no menu "Fornecedor" para ir direto ao cartão dele.

7Como limpar os filtros

Clique no botão "Limpar filtros", ao lado dos menus, para voltar a ver todos os fornecedores e zerar a busca de uma vez.

8O que cada cartão de fornecedor mostra

Cada cartão traz o nome do fornecedor, a especialidade, os produtos e marcas que ele trabalha, a localização (quando informada) e os botões de contato.

9O que significa o selo "Verificado"

É um selo dourado que só aparece quando a plataforma confirmou informações sobre aquele fornecedor. A ausência do selo não significa que o fornecedor não é confiável — apenas que a verificação ainda não foi feita.

10Como falar com um fornecedor pelo WhatsApp

Clique no botão "Chamar no WhatsApp" dentro do cartão do fornecedor. Ele abre uma nova aba direto na conversa com aquele fornecedor.

11Como acessar a comunidade de um fornecedor

Clique em "Acessar comunidade" para entrar no grupo ou canal daquele fornecedor. Alguns fornecedores têm mais de uma comunidade — nesse caso, você verá vários botões, um para cada assunto.

12O que fazer quando aparece "Link em breve"

Esse aviso aparece quando o fornecedor ainda não enviou aquele link (WhatsApp ou comunidade). Não é um erro — é só um espaço reservado até a informação ser cadastrada.

13Como usar o menu em celular

Em telas pequenas, toque no ícone de três linhas no canto superior direito para abrir o menu de navegação. Toque em qualquer link para ir até a seção e o menu fecha sozinho.

14Diferença entre "Fale conosco" e "Suporte Humano"

"Fale conosco" é o canal geral da plataforma. Já o "Suporte Humano" é exclusivo para quem já comprou e tem dúvidas sobre a lista de fornecedores — não é canal de vendas.

15Uso responsável das informações

Os contatos e comunidades listados aqui devem ser usados de forma ética, respeitando os termos de cada fornecedor. Veja mais no rodapé da página inicial.
